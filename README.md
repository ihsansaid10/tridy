# 🎨 TriDy - 3D OBJ Photobooth

**Turn your 3D models into stunning renders — right in your browser.**

3D OBJ Photobooth is a browser-based 3D visualization tool that lets you import, customize, position, and capture 3D models in an interactive environment. Inspired by 3D editing software, it brings essential modeling-scene controls and rendering features into a lightweight web application.

## ✨ Features

- 📦 **3D Model Import** — Import `.obj` and `.glb` models directly into the viewport.
- 🎨 **Material Customization** — Experiment with different materials, colors, roughness, and metallic properties.
- 💡 **Lighting Controls** — Adjust the scene's lighting to achieve different visual effects.
- 🌅 **Environment Customization** — Create different atmospheres for your renders.
- 🎥 **Interactive Viewport** — Navigate the 3D scene, adjust your view, and position objects.
- 📸 **Render & Export** — Capture your creations and export them as PNG or JPG images.
- 🛠️ **Object Controls** — Move, rotate, scale, and manage objects within the scene.
- 🖥️ **Browser-Based Workflow** — Create 3D renders without installing heavyweight 3D software.

## 🎯 Purpose

The goal of this project is to make 3D visualization more accessible by combining an intuitive interface with practical scene customization and image export tools.
